# GetPro Church — EJS templates

This folder will contain EJS templates for the GetPro Church module.

Subfolders:

- `public` — public church website pages
- `auth` — sign-in, registration, and password flows
- `member` — member portal screens
- `branch-admin` — branch-level administration
- `hq-admin` — headquarters / organization-level administration
- `partials` — shared layout and UI fragments
