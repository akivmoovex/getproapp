# Accessibility gaps

No accessibility program was implemented. D29-18 has no approved target.

These gaps remain:

| Gap | Current state |
|---|---|
| Keyboard path for clinical document create and finalize | Not reviewed in a browser this stage |
| Form errors | Document validation returns a code such as `invalid_input` or `invalid_document_type`. A screen reader announcement for those codes was not tested |
| Clinical units | Pain remains the stored 0–10 integer. No new unit or threshold was added |
| Contrast and focus | Not measured |

A browser pass is required before any of these can be called closed. This stage did not open one.
