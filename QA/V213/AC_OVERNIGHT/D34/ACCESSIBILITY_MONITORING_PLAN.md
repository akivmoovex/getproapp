# Accessibility and monitoring plan

D29-18 is pending. No screen list, contrast number, or monitor threshold was chosen.

Clinical screens still need, after that approval: keyboard use, readable errors, and unit labels on vitals. A browser pass is the evidence. None was run.

Monitors named in the specification, and still absent, are failed authentication, OTP delivery, authorization denials, queue age, critical-result acknowledgement, backup and restore, and import exceptions. A monitor must not contain an OTP code or clinical note text. Adding one does not activate OTP delivery.

`ACX-004`, `ACX-005`, and `ACX-006` stay outside the V2.13 release.
