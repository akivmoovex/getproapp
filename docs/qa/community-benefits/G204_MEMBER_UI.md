# G204 member UI

`/app/community/enroll` collects a preferred name and tells the member that enrollment is pending consent. `/app/community/pass` shows membership status, an issue action, a rotate action, and the fallback code after a server issue. The pages use labels, an alert or status role, and a layout that remains readable at 390, 768, and 1440 pixels.

The pages do not advertise an unapproved discount and do not show a wallet balance. A discount sentence appears only on the reception preview when the decision is eligible. The clinic B sentence in the mock browser comes from a fixture agreement marked active inside the test server and labeled `SYNTHETIC_NOT_POLICY`.
