# V212 External Media Contract

Database media metadata is classified in the ownership manifest. BlessBoard media assets are product-scoped; platform media folders, website media, and usage rows are shared organization-scoped metadata. The referenced filesystem/object-storage objects, public URLs, and shared assets require an independent storage contract.

Default policy is PRESERVE all external media. Future reset may archive or delete media only through a separately approved, identity-verified storage operation with orphan/reference checks and rollback evidence. No media was deleted or moved in Phase 3F. Media dependencies keep all reset scopes BLOCKED.
