# G231 clinical printing

Confirmed supported print actions include patient cards, billing/cashier
documents and the G224 laboratory result view. The laboratory result print
control is authorized by the existing request scope and renders the patient,
request, summary and status in a print-ready region.

SOAP notes, encounter summaries, referrals and radiology reports do not have
an equivalent independently verified print journey in this cycle. A browser
presence check would be insufficient, so these remain incomplete P1 coverage
where the source exposes no approved print contract. No PDF format or new
clinical document policy was invented.
