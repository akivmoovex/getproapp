# V2.13.2 release notes

Development candidate on branch V13. Not deployed. Hosted QA is not verified.

## FIXED_AND_VERIFIED

- BlessBoard and ActiveClinic About version is 2.13.2.
- Same-staff appointment overlap is checked inside the create, update, and reschedule transactions after a transaction-scoped staff advisory lock.
- An authorized clinician can append a vitals correction. The original observation row is not updated or deleted. A second correction of an already superseded row is rejected. Disposable HTTP and browser runs recorded the correction, the preserved original, and the stale retry.
- A staff-created patient keeps the phone through review, activates one existing record, sets a password, signs in, and reads that patient number back. An unknown public registration does not insert a patient.
- A new website section stays private until explicit publish. After publish, the heading, body, and an authorized https image reference render on the public page and survive reload.

These checks ran on the disposable G78 database and in database-free tests. They are not a hosted QA pass. Binary media upload was not enabled.
